개인정보처리방침 (WHAT'S TREND)

최종 수정일: 2026-09-24

1. 수집하는 정보

본 서비스는 사용자가 등록한 키워드(검색어)만을 수집합니다. 회원가입/로그인 기능이 없는 현재 버전에서는 개인을 식별할 수 있는 정보를 수집하지 않습니다.

2. 외부 데이터 활용

본 서비스는 다음 외부 API를 통해 공개적으로 제공되는 데이터를 수집·가공합니다:

  • YouTube Data API (영상 개수 통계)
  • Google News RSS (뉴스 언급량)
  • NAVER 검색어 트렌드 API (검색 관심도 지수)
  • Google Gemini API (트렌드 설명 생성)

수집된 데이터는 키워드·날짜·집계 수치 형태로만 저장되며, 원본 영상·기사·이미지 등은 저장하지 않습니다.

3. 데이터 보관

집계된 트렌드 데이터는 서비스 제공(성장률 계산) 목적으로 보관되며, 개인정보를 포함하지 않습니다.
